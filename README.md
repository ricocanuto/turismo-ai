# 🌍 turismo_ai

> Aplicação com Inteligência Artificial para recomendação de destinos e experiências turísticas.

Projeto que une minha experiência no setor de turismo com desenvolvimento Full Stack, aplicando IA para gerar sugestões personalizadas de viagem.

---

## 🚀 Tecnologias

- React  
- Node.js  
- API de IA  
- MongoDB / PostgreSQL  

---

## 🧠 Funcionalidades

- Recomendações inteligentes de destinos  
- Sugestão de roteiros personalizados  
- Assistente virtual para dúvidas  
- Análise de preferências do usuário  

---

## 🎯 Objetivo

Aplicar Inteligência Artificial no setor turístico para gerar recomendações inteligentes, melhorar a experiência do viajante e automatizar atendimentos.
